# TrabajoPractico3
trabajo practico 3. Integrantes: Cuevas-Ocampo-Herrera-Velazquez-Rassi

 *Proyecto: Análisis de Datos de Fórmula 1 (C# Console App)

Este proyecto es una aplicación de consola en C# que permite analizar datos reales de la Fórmula 1 correspondientes a los últimos 5 años. Utiliza un archivo CSV como fuente de información y ofrece distintas funcionalidades para consulta y análisis de estadísticas.

 *Archivo de datos utilizado

El programa lee un archivo CSV con registros de pilotos, equipos, resultados de carreras y puntos obtenidos.
-Nombre del archivo: f1_last5years.csv

 *Funcionalidades del Menú
1. Buscar podios de un piloto	(Muestra cuántos podios logró un piloto en total)
2. Datos de campeonato de un equipo en un año	(Lista puntos obtenidos por los pilotos del equipo para una temporada específica)
3. Mayor remontada	(Encuentra qué piloto avanzó más posiciones en una carrera)
4. Listar equipos en orden alfabético	(Muestra todos los equipos sin repetirse y ordenados)
5. Mostrar todos los datos	(Imprime en pantalla toda la tabla del CSV)
6. Calcular la posición promedio de un piloto	(Calcula el promedio de posición final en las carreras de un piloto)
7. Salir	(Finaliza el programa)
   
 *Tecnologías utilizadas

Lenguaje: C#

Framework: .NET Console Application
